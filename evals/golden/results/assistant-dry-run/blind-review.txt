Important limitations and required wording
1. Recorder coverage: JSONL is an instrumented interaction transcript containing displayed context, the three helpers' commands/results, and the final proposal/explanation. It is not the whole assistant/backend session. No captured entry or prepared checkout exposed expected answers, but these artifacts cannot independently prove no outside filesystem/network reads, inherited parent context, cross-agent messages, or wider-tool calls. Do not call this enforced isolation or a complete backend transcript. The recorder itself explicitly discloses this.
2. Local integrity is not external attestation: local timestamps, hashes and exclusive proposal creation corroborate an internally consistent preserved sequence; they do not cryptographically attest when an evaluator read gold or prove files were never changed before sealing. The exporter does not read gold, and all recorded decisions precede the recorded seal.
3. Different runner: same source configuration and normalized inputs were supplied, but Codex coding-assistant subagents are not the configured claude-sonnet-5-5 hosted engine. The manifest does not expose an exact backend model/version. One assistant handles five sequential cases, so within-batch carry-over remains possible. The study is not independent repeated trials.
4. Untested controls: GitHub trigger/preflight behavior, token permissions, actual label/comment writes and caps, safe-output orchestration, real threat detection, AWF firewall/network egress, hosted budgets/rate limits, bot identity attribution, cancellation/kill switch and model cost accounting are not tested by this local run. A scripted no-write recorder should not be presented as testing those barriers.
5. In the final manifest, the ambiguous provider_calls field has been replaced by anthropic_api_calls:0, coding_assistant_inference_used:true and an explicit cost-scope caveat. Existing Codex inference occurred; precise backend cost was unavailable. The report now makes this distinction correctly.
6. Current-vs-historical evidence: the source, helper and prepared-input consistency checks are strong, but this audit did not re-fetch historical source issues. Original annotation, historical reconstruction, association-at-fetch-time and corpus/hint-selection limitations remain. The snapshot reduction improves this run's observable context; it does not retroactively validate prior live runs.
7. One repetition cannot establish pass^3 or the frozen k=3 shadow-deployment acceptance test, regardless of this run's 0.80 pass rate or 0.56 cost. The reported Wilson interval is a descriptive calculation over the selected 25 cases, not a guarantee of future behavior or a grade.
